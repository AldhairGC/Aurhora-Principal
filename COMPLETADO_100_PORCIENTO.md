```bash

npm start
```

### Agregar Nuevas Traducciones
1. Editar `src/messages/es.json` (agregar clave)
2. Editar `src/messages/en.json` (agregar traducción)
3. Editar `src/messages/pt.json` (agregar traducción)
4. Usar en componente: `t('nueva.clave')`

### Usar en Componentes
```typescript
import { useTranslations } from 'next-intl';

export default function Component() {
  const t = useTranslations();
  
  return (
    <div>
      <h1>{t('header.title')}</h1>
      <p>{t('hero.description')}</p>
    </div>
  );
}
```

### Navegación Interna
```typescript
import { Link } from '@/navigation';

// Automáticamente usa el locale activo
<Link href="/quienes-somos">
  {t('header.quienesSomos')}
</Link>
```

### Cambiar Idioma Programáticamente
```typescript
import { useRouter } from '@/navigation';

const router = useRouter();
const pathname = usePathname();

// Cambiar a inglés
router.replace(pathname, { locale: 'en' });
```
